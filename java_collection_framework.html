List

Implementation Ordering Duplicates Complexity Interview Notes
ArrayList Insertion Order Yes get → O(1)
add → O(1) Amortized
remove(index) → O(n) 		Default List implementation
LinkedList Insertion Order Yes add/remove ends → O(1)
get → O(n) 		Also implements Queue & Deque
Vector Insertion Order Yes Similar to ArrayList Synchronized (Legacy)
Stack LIFO Yes O(1) Don't use. Use ArrayDeque.

Set

Implementation Ordering Duplicates Complexity Interview Notes
HashSet No No O(1) Fast lookup
LinkedHashSet Insertion Order No O(1) Ordered HashSet
TreeSet Sorted No O(log n) Red Black Tree
EnumSet Natural Enum Order No O(1) Enums only

Queue / Deque

Implementation Use Complexity Interview Notes
LinkedList Queue offer/poll O(1) BFS
PriorityQueue Heap offer/poll O(log n) Min Heap by default
ArrayDeque Stack & Queue O(1) Preferred over Stack

Map

Implementation Ordering Null Keys Complexity Interview Notes
HashMap No 1 Null Key O(1) Most Used
LinkedHashMap Insertion Order Yes O(1) LRU Cache
TreeMap Sorted No O(log n) Red Black Tree
Hashtable No No O(1) Legacy Thread Safe
ConcurrentHashMap No No O(1) Thread Safe
WeakHashMap No Yes O(1) GC removes weak keys
IdentityHashMap No Yes O(1) Uses == instead of equals()
EnumMap Enum Order No O(1) Enums only

Must Remember

  • HashMap → Average O(1)
  • TreeMap → O(log n)
  • HashSet → O(1)
  • TreeSet → O(log n)
  • PriorityQueue → Min Heap by default
  • ArrayDeque is preferred over Stack
  • LinkedList implements List, Queue and Deque
  • Map is NOT part of Collection interface
  • TreeMap & TreeSet are implemented using Red-Black Trees
  • HashMap allows one null key; Hashtable does not allow null keys or values
