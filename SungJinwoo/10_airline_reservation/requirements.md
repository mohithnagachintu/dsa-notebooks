# Airline Reservation

## Problem Statement
Design an extensible object-oriented system for Airline Reservation.

## Functional Requirements
- Gather and model the core entities.
- Support CRUD-like operations relevant to the domain.
- Design for extensibility.
- Support multiple implementations where appropriate.

## Non-Functional Requirements
- Follow SOLID.
- Prefer Composition over Inheritance.
- High cohesion, low coupling.
- In-memory only.
- Ignore database/networking unless modeling requires an abstraction.

## Deliverables
- Functional requirements
- Entities
- Classes
- Interfaces/ABCs
- Enums
- Relationships
- UML
- Design Patterns
- Python implementation
